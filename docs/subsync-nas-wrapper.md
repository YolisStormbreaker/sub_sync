# Subsync на Synology NAS: обёртка для субтитров без Plex

Состояние на 2026-10-23. Источник истины для кода: `/volume1/docker/subsync-tools/subsyncd/` на NAS (192.168.1.52, DSM 7.4.1; доступ только через webssh-терминал). Предыдущая версия панели (stage9) лежит в `/volume1/docker/subsync-tools/bak-s9/`.

## Что делает
Сканирует только `Animation`, `Anime`, `Movies`, `TVshows` в `/volume1/video`, скачивает недостающие субтитры (ru + язык оригинала) с OpenSubtitles, синхронизирует **только тайминг** (текст байт-в-байт тот же; проверка `strip_times(out)==strip_times(data)`) и кладёт рядом с видео. Работает с низким приоритетом CPU/IO.

## Жёсткие правила
- Ни я, ни движок не меняем текст субтитров. Тестовые варианты имён (`.F_acts` и т.п.) допустимы только для тестов.
- e01/e02 The Mentalist s06 не заменять.
- Любые новые удаления и новые постоянные задачи на NAS — только после явного «да».
- Оригинал = английский для Doctor Who, The Mentalist, «Жизнь с Луи», Black Mirror; для остального TMDb; выбор языка/дорожки в панели.

## Алгоритм
Модель «ступенек» по актам: у ru-файлов OpenSubtitles постоянный сдвиг внутри акта и скачки на рекламных паузах. Подгонка `lag(t)=p*t+q_k` по эталону: либо по уже синхронизированным англ. субтитрам (цепочка), либо по VAD аудио. Каркас с плейсхолдерами сохраняет текст.

## Контроль качества (`quality.assess`)
Вердикт `ok` или `review`. Пороги (начальные): доля стартов реплик в пределах 0,6 с от эталона ≥ 0,80; покрытие окон ≥ 0,85; для аудио покрытие ≥ 0,75 и медиана остатка ≤ 0,40 с; актов ≤ 8; |остаточный наклон| ≤ 0,01. Если эталонный англ. файл не подтверждён, ru-файл проходит только при near06 ≥ 0,90 (`CHAIN_NEAR_UNCONFIRMED_REF`; ослаблено 2026-10-20 с «всегда review» по решению пользователя после его прослушиваний). Остальные пороги прежние.
Режимы: `write` (тесты с `--dest`), `gate` (`--apply`: рядом с видео только `ok`, остальное в хранилище проверки), `hold` (всё в хранилище). Журнал по каждому файлу: `<state>/quality.jsonl`.
Прогон по s06 e05–e22 (2026-10-19/20): 36 файлов, шлюз пропускает только e09 и e21; 16 ru-файлов с near06 0,87–0,998 попали в `review` только из-за неподтверждённого англ. эталона. Пользователь по выборочным прослушиваниям: высокая уверенность = субтитры реально работают, расхождения только в начале или чуть в середине реплик. После ослабления `requalify.py` (переоценка удержанных по сохранённым метрикам, без скачивания; `docker exec -w /t/subsyncd subsyncd <python venv ffsubsync> requalify.py /state /video [--apply]`) записал 9 ru-файлов (e12, e13, e15–e18, e20–e22, near06 0,964–0,998). Остались на проверке e14 (0,875) и e19 (0,871) и 16 англ. эталонов (по звуку не подтверждены).

## Приоритеты
Три стадии: сканирование, скачивание, синхронизация. Значения 1 (первым) … 9 (последним), 0 = пауза. Файл сильнее папки, длиннее путь побеждает. По умолчанию: TVshows 1, Anime 2, Animation и Movies 3.

## Веб-панель (порт 8742, HTTP Basic, логин любой, пароль в `<state>/web_password`)
Все страницы показывают библиотеку деревом «раздел → сериал → папка сезона → серии», серии по номеру (s06e02 перед s06e10), общий фильтр: слова из названия, `s06e05`, `6x05`, `s06`, `e05`. `/` язык оригинала и дорожка; `/review` прослушивание (клипы по 40 с оригинальной дорожки + реплики, одобрить / отклонить / повторить; одобрение копирует файл байт-в-байт рядом с видео), плюс фильтры по статусу и языку; `/prio` приоритеты; `/quality` журнал (сортировка по библиотеке или по времени). Тест `test_web_ui.py` гоняет страницы в Chromium.

## Метрики качества OpenSubtitles (проверено запросом 2026-10-20)
Поля кандидата: `download_count`, `new_download_count`, `ratings`, `votes`, `from_trusted`, `hearing_impaired`, `hd`, `fps`, `release`, `uploader.rank`, `moviehash_match`. Синхронизации среди них нет. На реальном поиске The Mentalist s06e11: `ratings` ненулевой у 1 из 15 англ. результатов, `votes` почти всегда 0, `fps` часто 0.0, ru-кандидатов всего 2. `search` уже исключает `ai_translated`, `machine_translated`, `foreign_parts_only`; `pick` ранжирует по совпадению хеша, сходству релиза, fps, штрафу за `hearing_impaired`, `download_count` как тай-брейку. Настоящая метрика — вердикт шлюза после синхронизации.

## Аудио-пример на странице `/` (2026-10-23, выкачено, контейнер перезапущен 14:58 UTC)
У каждого файла в списке «Язык оригинала и дорожка» кнопки `▶ <номер дорожки> · язык · название`, плеер встаёт в строку файла; 20 с из середины фильма, кнопка «другой фрагмент» сдвигает точку (50/30/70/15/85 % длительности). Эндпоинт `GET /api/clip?path=<rel>&track=<n>&t=<с>&len=<с>` (`review.file_clip`): путь только внутри `Animation/Anime/Movies/TVshows`, без `..`, `Plex Versions`, симлинков наружу; дорожка 0–31; длина 5–60 с; MP3 96k, кэш `<state>/tmp/clips` (сутки), один ffmpeg за раз (`CLIP_LOCK`). Проверено на NAS: Doctor Who s01e03, обе дорожки, клип 20,04 с за 1–2 с, `Others/…` даёт 400. Откат: `bak-s11/` (web.py, review.py). Патч-скрипт `in/apply_s12.py`, промежуточные `in/s12.p1`, `in/s12.p2`, `in/stage/` можно удалить (только с разрешения).

## «Не найдено» и подсказки поиска (stage12, выкачено 2026-10-23)
Причина пустого поиска теперь записывается в `<state>/missing.json` (ключ `видео|размер|язык`: `code`, `ru`, `en`, `query`, `others`) и видна на странице `/missing` («Не найдено»). Коды: `other_langs` (серия в базе есть, но не на этом языке; ждать, повтор через 7 дней), `unknown` (базе неизвестно название: нужна подсказка), `no_guess` (имя файла не разобрать: нужно «Название SxxEyy» или «Название год»), `special` (серия 0), `filtered` (всё отброшено фильтром). Причина собирается переписью без фильтра языка (`OS.languages_found`), скачивания не тратятся. Подсказка (`<state>/searchhints.json`, `{путь: {title, tmdb, at}}`, действует на папку, самый длинный путь побеждает) меняет запрос: `parent_tmdb_id` для серий, `tmdb_id` для фильмов или своё название вместо `query`; новая подсказка снимает 7-дневное ожидание. Ночь 2026-10-22: 33 файла без субтитров, из них 32 — Abbott Elementary S05 на ru (в базе есть en, es и другие, ru нет), остальное: спецвыпуск Doctor Who s12e00, имя `s11e09HDRip` без разделителя (разбор `media.guess` исправлен: после номера серии допустимы буквы), Black Mirror Bandersnatch без года. Старые 35 записей добиты `diag_missing.py` (запуск внутри контейнера, только поиск). TMDb id: Doctor Who (2005) 57243, Abbott Elementary 125935.

## Страница `/` после переделки (stage12)
Карточка файла: строки статуса по-русски (откуда язык, как определена дорожка, почему не определена, с цифрами порога), по строке на реальную дорожку с кнопками «▶ Послушать» и «Это оригинал»; кнопки «ОК» и статический список 0–5 убраны; нумерация дорожек человеческая (дорожка 1 = индекс 0). Разделы папки: «Файлы, где нужен ваш выбор», «В очереди на автоопределение», «Выбрано вами» (с отменой). Выбор файла сохраняется сразу (`overrides.json`, `{lang, track}`). `Overrides.lookup` теперь сливает поля: дорожка, выбранная для файла, не скрывает язык, выбранный для папки; `Overrides.source(rel, поле)` говорит, откуда взято. Автоопределение дорожки: теги, TMDb, затем сравнение звука каждой дорожки с субтитрами оригинала; уверенным результат считается, если обе метрики выбрали одну дорожку, разрыв контраста ≥ 0,03 и разрыв начала реплик ≥ 0,10 с (пример: Doctor Who s01e03, дорожки 0,195 и 0,218, разрыв 0,023, поэтому «неясно»). Откат: `bak-s12/` (web.py, main.py, osapi.py, overrides.py, web_pages.py, media.py), копии логов контейнера до перезапуска `in/subsyncd-before-s13*.log`. Перезапуск `docker rm -f subsyncd` стирает логи контейнера, результаты и состояние остаются.
Язык дорожки (stage12b, выкачено 2026-10-23): у файлов с ≥2 дорожками у каждой дорожки выбор языка, хранится в `overrides.json` как `tlangs` (`{"1": "ru"}`, только на уровне файла; API `/api/override` принимает `tlangs`, без поля сохраняет прежние метки). `resolve.relabel` подставляет метки в список дорожек до `original_audio`, `pending_detect` и `detect_track`; сохранённое сравнение звука, сделанное по другому набору кандидатов, отбрасывается (`_entry(..., cands)`). Пометка русских дубляжей делает оригинал известным без прослушивания и подсказывает язык оригинала. Прокрутка: после сохранения выбора страница не прыгает вверх; `keepView(path)` запоминает соседнюю карточку и её смещение от верха окна, держит высоту списка на время перерисовки и доскролливает на разницу (проверено в Chromium: смещение следующей карточки 0 px). Откат: `bak-s14/`.
Тесты: `test_missing.py`, `test_web_ui.py` (Chromium), `test_gate.py`, `test_flow.py`, `test_all.py`. Служебные файлы `in/s13/`, `in/apply_s12.py`, `in/s12.p*`, `in/stage/`, `in/probe*.py` можно удалить только по разрешению.

## Иконка в DSM
Пакет `Subsync` (пассивный SPK, `.url` на `http://NAS:8742/`), собран `mkspk.py` (только stdlib), установлен через `synopkg install`. Остальные ярлыки пользователя (HomeAssistant, qBittorrent, RouterLord, RouterLapin, XUI) сделаны без пакетов: каталог `/volume1/@appstore/dsm-shortcuts/<Имя>/{config,images/<имя>_{16,24,32,48,64,72,96,128,144,256,512}.png}`, симлинк `/usr/syno/synoman/webman/3rdparty/<Имя>` на него, `config` с блоком `.url` (title, desc, icon `images/<имя>_{0}.png`, type url, protocol, port, url, allUsers). Причина пропавшей иконки и записи в списке (2026-10-23): каталог `ui` пакета и `ui/images` были `drwx------` у пользователя `Subsync`, веб-сервер DSM (`http`) не мог их прочитать; исправлено `chmod -R a+rX /var/packages/Subsync/target/ui` (проверено `su http`). Из `config` убраны лишние `grantPrivilege`/`advanceGrantPrivilege` (оригинал в `bak-s11/Subsync-ui-config.orig`), теперь запись идентична ярлыку qBittorrent; `SYNO.Core.Desktop.Initdata` отдаёт её как `com.halcyon.Subsync`. Права могут сброситься при переустановке пакета: тогда повторить `chmod`. Если после обновления страницы DSM иконки всё ещё нет, запасной путь: сделать ярлык по схеме `dsm-shortcuts` и удалить пакет (удаление только по «да»).

## Особенности NAS
python3 3.8 без numpy на хосте (numpy, webrtcvad, ffmpeg внутри контейнера `chryses/subsyncarr-ng` через `run.sh`); нет `patch`; curl на хосте падает; передача файлов heredoc'ом по ~55 строк (base64 архива) с sha256; `clear`/`reset` перед выводом может съесть вывод; время в логе контейнера UTC, на хосте UTC+3.
Квота OpenSubtitles: по ключу 100/день (сброс 00:00 UTC), с логином 20/день; сырые оригиналы кэшируются в `/volume1/docker/subsync/raw/`, повторный прогон квоту не тратит.
